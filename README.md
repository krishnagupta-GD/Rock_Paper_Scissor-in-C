# Rock_Paper_Scissor in C

A simple console-based Rock Paper Scissors game written in C.  
This project was built as a first-semester programming exercise to practice fundamental concepts like functions, loops, conditionals, random numbers, and input validation.

## Features

- Classic Rock, Paper, Scissors gameplay against the computer.
- Input validation to ensure only valid moves are accepted.
- Score tracking across multiple rounds (optional – included in the enhanced version).
- Option to play again.
- Clean, commented code for easy understanding.

## How to Run

### Prerequisites

- A C compiler (e.g., GCC) installed on your system.
- A terminal or command prompt.

### Compilation

```bash
gcc Game.c -o rps
